CAROLOGY CUSTOMS – CLOUDFLARE PROTOTYPE
======================================

This folder is ready for Cloudflare Pages Direct Upload.

UPLOAD
1. Unzip the package.
2. In Cloudflare, open Workers & Pages.
3. Create a Pages application.
4. Choose Direct Upload.
5. Upload the CONTENTS of this folder, with index.html at the root.

FILES
- index.html
- styles.css
- script.js
- assets/
